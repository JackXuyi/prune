# 版式骨架与高度预算

## 1. 窗口数学（唯一尺寸 1000×700）

```
1000 宽 = 58 rail + 942 内容
 700 高 = 40 titlebar + 660 内容
```

- rail：`w-[58px] shrink-0 border-r border-hairline-soft`
- 主区内容宽 = `宽 − rail − 侧栏 − padding`。设计稿里任何一行文字的可用宽度都按这个算，不要按窗口宽算。

## 2. 页级骨架（顺序不可换）

```
┌ Ribbon 状态带      62px   shrink-0   3–7 段图标读数
├ Hero 主区块       118–160px shrink-0 该页核心量（环 / 构成条 / 主表）
└ 内容区            flex-1 min-h-0    磁贴网格 / 列表（唯一可滚动区）
```

可选插入：

- **提醒带**（62px，如泄漏嫌疑、异常提示）：**无内容时整条不渲染**，不占位不留白。
- **成绩单 / 汇总条**（74px）：放在最底部，`shrink-0`。

## 3. 高度预算表（示例：内存页）

| 区块 | 高 | 备注 |
|---|---|---|
| padding-top | 13 | |
| Ribbon | 56–62 | 6 段 |
| gap | 9 | 区块间距固定 9–10 |
| Hero | 118 | 构成条 + 压力环 |
| gap | 9 | |
| 磁贴行 | 104 | 2 列 |
| gap | 9 | |
| 提醒带 | 62 | 无命中则 0 |
| gap | 9 | |
| 列表 | 余量 ≈ 250 | 5–6 行 |
| padding-bottom | 14 | |

算账公式：

```
余量 = 660 − padding(27) − Σ区块 − gaps(9 × n)
```

余量 < 0 就砍区块（或把两行磁贴压成一行三块），**不要**引入滚动——滚动在主窗口里等于「这页没设计完」。

## 4. 栅格

| 场景 | 写法 |
|---|---|
| 卡片网格 | `grid gap-2.5 [grid-template-columns:repeat(auto-fill,minmax(240px,1fr))]` |
| 固定 2 列磁贴 | `grid grid-cols-2 gap-[9px]` |
| 侧栏 + 主区 | 侧栏 `shrink-0`，主区 `min-w-0 flex-1` |

- **列数不写死**：1000px 下 `minmax(240px,1fr)` 得 3 列；窗口变宽自动增列。
- 240px 是「图标 + 名称 + 三枚小簇」能排下的实测下限。
- 窄卡里指标必须**单列四行**；2×2 会把比例条压到 ~20px，失去量感。

## 5. 现役页面结构（照着改，别另起炉灶）

### 总览 `StatsBoard`

```
StatusRibbon(7 段: CPU/内存/磁盘/↓/↑/端口/电池)
Hero 可回收环(134) + L1–L4 徽标图例 + CTA
InfoTile × 6（2×3：内存/CPU/磁盘/端口/下载/设备）
成绩单（奖章 + 大数字 + Top3 迷你条）
```

### 应用 `AppResourceGrid`

```
AppSummaryRibbon(7 段：应用/进程/内存合计/↓/↑/端口/连接，点段切排序)
工具条（搜索图标 + 排序图标 chip + 基准 Glyph + 大户 chip）
卡片网格（auto-fill 240px）：头簇三枚小簇 + 单列四行指标
```

### 内存（设计稿已定，落码中）

```
Ribbon(6 段：已用环/可用/压缩/Swap 环/换页/压力电平条)
Hero 内存构成堆叠条 + 压力环
磁贴 ×2（交换空间阈值带 / 换页颠簸走势）
泄漏嫌疑带（有命中才出现）
换出大户列表（比例条 / 已换出 / Δ24h / 占比）
```

### 侧栏列表（内存家族）

```
头 38px：标题(dim) + 排序icon + 导出icon + 计数(mono)
行 34px：AppIcon 22 + 名称 + 进程数徽标 + 总量(mono) + 换出占比细条(46×2.5)
展开：子行 26px（名称 + 工作区标签 + 值）
```

## 6. 视觉层次（一个版面只有一个主角）

- 每屏**只有一个 25px+ 的大数字**（Hero）。其余读数 17–23px，再小是 12px 表格值。
- 五个同权重数字并列是反模式（内存页曾把 5 个统计格并排 → 视线无处落脚）。
  构成关系用**堆叠条 + 图例**表达，不用并列数字。
- 卡片顶缘洗光 `linear-gradient(180deg, color-mix(tc 6%), transparent 60%)`，
  底缘 2px 发丝线 `color-mix(tc 40%)`——全产品统一这两样，别加第三种装饰。
