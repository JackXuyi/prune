设计要点
① Ribbon：3–7 段「图标 + mono 读数」，百分比套环、容量/速率用芯片，段内不放名词标签。
② Hero：一个主角数字（25px+），构成关系用堆叠条而不是并列数字。
③ 磁贴：图标/环 + 标题 + 读数 + 一行口径 + 微图表，四层缺一即空卡。
④ 列表：唯一可滚动区，数值列右对齐 + tabular-nums。
纪律
· 读不到写 — 或原因，不画 0；平台无口径整段隐藏。
· 推导值用斜纹 + tooltip 写明公式，不伪装实测。
· 只用域色令牌；浅色主题有覆盖且 ≥ 4.5:1。
· 高度总账 ≤ 660，不引入滚动。
