# M20 局域网拓扑视图 · 方案

> 需求：把当前扫描到的设备列表做成一个好玩的交互页面，用**网络拓扑图**展示对应设备。
> 状态：方案已确认 → 详细 spec 见 docs/m20-lan-topology-spec.md（实施依据）。对应代码：`src/components/LanBoard.tsx`（挂载点）、新增 `src/components/LanTopology.tsx`。
> 前置：M18 设备卡 + M19 时间线已落地（`firstSeen` / `lastSeen` / `isNew` 三字段可用）。

## 1. 定位与入口

**不是新 tab，是 LanBoard 内的第二种视图。** 「端口」tab 内的局域网分段已有完整的空态 / 扫描进度 / 筛选 / 详情弹窗链路，拓扑视图复用这一整条数据链路（`useLanStore`），只是把「设备网格」换成「拓扑画布」——入口成本最低，数据零新接线。

| 项 | 决策 |
|---|---|
| 入口 | LanBoard 筛选条右侧加「卡片 / 拓扑」二态切换（与重扫按钮同排） |
| 数据源 | `useLanStore.snapshot`（现有），不新增 IPC、不新增扫描逻辑 |
| 详情 | 点击节点复用现有 `LanDeviceDetailModal`（含 M19 加入/活跃时间） |
| 视图切换状态 | `useState`（会话内记忆即可，不落 localStorage——设备页停留时间短） |

## 2. 渲染技术选型：零依赖自绘

**不引入 d3-force / reactflow。** 理由：

- 依赖预算：项目 dependencies 只有 react / zustand / tauri-api，为一个装饰性视图引入 ~40KB+ 的图布局库不值；
- 设备规模小（实测 ≤ 30 台），星形布局用**确定性排布**就够了，不需要力导仿真收敛；
- 自绘 SVG 边 + 绝对定位 HTML 节点，能直接复用现有 design tokens（hairline / accent / warn）与 `DeviceKindIcon`，视觉与设备卡天然同源。

**布局语义：初始排布，不是仿真。** 拖过的位置记住、不回弹、不自动重排——「好玩」来自可摆弄，不来自物理模拟。

## 3. 布局算法（确定性星形）

```
                ┌── 环形设备（按 IP 稳定排序 + 哈希抖动 ±10°）
                │
   网关 ●───────● 本机（内圈，网关正下方 r=84）
        ╲  ╱
      （其余设备均匀落外环 R）
```

| 规则 | 细节 |
|---|---|
| 网关 | 画布中心 `(w/2, h*0.46)`；无网关时本机顶替中心位 |
| 本机 | 内圈固定偏移（网关正下方 r=84），与网关视觉强绑定 |
| 其余设备 | 单环分布：`R = clamp(130, min(w,h)/2 − 100, 260)`；角度 = `i/n·2π − π/2 + jitter(ip)` |
| 抖动 | `hash(ip) → ±10°`——确定性（重渲染不跳位）+ 打散均匀角度的机械感 |
| 位置记忆 | 位置存 `Record<ip, {x,y}>`；布局重算只**补缺失的 key**（新扫描进来的设备落初始位，拖过的不动） |
| 画布尺寸 | 容器 `ResizeObserver` 实测；高度固定 460px，宽度自适应 |
| 拖拽夹紧 | 节点中心 clamp 在画布内边距 30px / 26px，不允许拖出可见区 |

## 4. 交互规格

| 交互 | 行为 |
|---|---|
| 拖拽 | `pointerdown` 捕获 → `pointermove` 更新位置（window 级监听）→ `pointerup` 释放；位移 >4px 判定为拖拽，抑制紧随的 click |
| 点击 | 打开现有 `LanDeviceDetailModal`（复用 M19 时间线行） |
| 悬停 | 高亮该节点 + 所有相连边（其余边降透明度）；节点轻微放大 |
| 新设备 | `isNew` 节点加 ping 脉冲环 + 「新」badge——拓扑上一眼看出刚入网的设备 |
| 连了我 | `inbound` 非空 → 本机到该设备画 **accent 虚线**（区别于普通网关实线，安全信号延续设备卡的 warn 前置原则） |
| 离线 | 边变虚线、节点置灰（opacity 45%），仍参与布局——「活跃 x 前」正是用户想看的 |
| 扫描中 / 空态 | 不进拓扑：沿用 LanBoard 现有进度条与空态分支（切换按钮只在有快照后出现） |

## 5. 视觉结构

```
┌─ 画布（rounded-[12px] 边框，深色底 + 微点阵纹理）────────────┐
│   ·   ·    （SVG 边层：pointer-events-none）        ·   ·  │
│        ╲    ╱                                              │
│    ●────●网关────●                                  │
│        ╱  │  ╲          节点 = 46px 圆形 tile + DeviceKindIcon │
│      ●    ●本机   ●           + 底部 96px 宽标签（名称/IP）    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
  拖拽节点重排 · 点击节点看详情        ● 本机 ● 网关 ● 新设备 ─ 离线 ┄ 连了我
```

- 节点 tile 配色与设备卡同源：网关/本机 accent 系，普通设备 `white/[0.05]` + hairline 描边，图标用现成 `DeviceKindIcon`（`size=17`，与卡片一致）。
- 标签：hostname 命中显 hostname，否则回退类型词（与卡片口径一致，不编造）。
- 图例一行置于画布下方（弱色小字），不占画布空间。

## 7. 边界与已知限制

| 边界 | 处理 |
|---|---|
| 浏览器 dev（非 Tauri） | store 本来就给 null 快照 → 空态，无假数据 |
| 设备数多（>20） | 环半径自适应 + 抖动错位；标签可能偶有交叠，属已知可接受（可拖开） |
| 快照刷新（重扫后） | 新 ip 落初始位；消失的 ip 位置残留在 map 中不渲染（无害，随组件卸载释放） |
| 只有一台网关没有本机 | 本机节点缺席时只画网关居中 + 环形设备，不画 inbound 线 |
| 动画偏好 | ping 脉冲用 Tailwind 内置 `animate-ping`，跟随系统 reduced-motion 由 Tailwind 媒体查询自动降级 |

## 9. 待确认

1. **拓扑里离线设备**要不要像卡片视图一样默认藏进「展开」？当前方案是画布上直接显示（置灰虚线），信息更全但节点更多。
2. **视图切换位置**：放筛选条右侧（方案现状）还是指标卡上方独立一行？前者省一行高度，后者更显眼。
3. 「好玩」的度：当前是「可拖拽 + 脉冲 + 悬停高亮」，没做自动浮动动画（idle 浮动会持续重绘边）。要不要加轻微 idle 浮动（代价是 SVG 边每帧重算）？

## 10. 落地纠偏与验收（T5 浏览器走查，2026-11-12）

T1–T4 由并行会话提交后补齐走查（`pnpm dev` + 注入 6 台设备快照：网关 / 本机 / 新设备 / NAS / 两台离线）。**发现 4 处缺陷，全部已修：**

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | `mi-tv`（正下方 90°）只剩文字，圆被吃进「本机」的 IP 行 | 环半径 `R` 取 `min(w,h)/2−100 = 130` < 本机内圈偏移 84 + 本机标签高度，正下方环节点与本机标签重叠 | 环半径下限改为「本机标签净空」`SELF_OFFSET + 92`，并与画布垂直可用带取小 |
| 2 | 顶部「新」badge 被画布上沿裁掉一半 | 中心位固定 `h*0.46`，环半径变大后顶部节点越界 | `cy` 改为按 `R` 反推：`clamp(h*0.46, PAD_TOP+R, h−PAD_BOTTOM−R)`，PAD_TOP 46 / PAD_BOTTOM 62 |
| 3 | 切「卡片」再切回「拓扑」，拖过的节点回原位 | 视图切换用三元分支 → `LanTopology` 卸载，`pos` state 丢失（违反 T2「切换来回不丢状态」） | 两视图常驻、用 `hidden` 切换；`ResizeObserver` 在宽高为 0（隐藏）时跳过重算，避免 0 尺寸把布局算歪 |
| 4 | 拖到画布边缘时标签被裁（实测 `ds220` 拖到 `x=30`，节点盒宽 110） | 夹紧值 30/26 小于节点盒半宽/半高 | `CLAMP_X = 58` / `CLAMP_Y = 44`（约半宽 55、半高 42 各加 3/2） |

**顺带主题化**：画布底色 `bg-[#0b0e11]` → `bg-surface-sunk`、点阵 `rgba(255,255,255,0.05)` → `var(--color-hatch)`、边线 `rgba(255,255,255,0.15/0.4)` → `var(--color-hairline)` / `var(--color-ink-dim)`、普通节点 `bg-white/[0.05]` → `bg-chip`——原先浅色主题下是一整块黑画布。离线节点透明度 0.45 → 0.55（浅色下 IP 几乎读不出）。
