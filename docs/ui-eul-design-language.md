## 1. 三条硬原则

### 1.1 图形优先（Graphic first）

- **每个视觉区块必须有一个图形锚点**：图标、环、条、点阵、走势线之一。没有图形锚点的区块视为未完成。
- **图标不是装饰**：图标位承载语义（这是哪个域），所以图标必须用域色、必须在读数左侧、尺寸统一（24–26px）。
- **图标即标签**：能靠图标 + 数值说清的，不写名词。标题允许存在，但只能是 11px `text-ink-dim` 的弱化小字，且不得比读数更抢眼。
- **趋势优先于陈述**：能画走势（sparkline）/ 占比（环）/ 分布（点阵）的，不要写成「较高 / 正常 / 良好」。

### 1.2 颜色即语义（Color as language）

域色一旦分配，全产品一致，不得跨域借用：

| 域 | 令牌 | 深色 | 浅色 | 说明 |
|---|---|---|---|---|
| 总览 / 存储 / 品牌 | `--color-accent` | `#34d399` | `#0e9e6e` | 也用于「可回收 / 安全」 |
| CPU | `--color-domain-cpu` | `#a78bfa` | `#7c5cd6` | |
| 内存 / info | `--color-info` | `#6aa9ff` | `#2273cc` | 内存页主色 |
| 网络 | `--color-domain-net` | `#22d3ee` | `#0e9cba` | |
| 端口 | `--color-domain-port` | `#f2a35c` | `#b87333` | 与 warn 分离，避免「端口=告警」 |
| 设备 | `--color-domain-device` | `#f072a8` | `#bf4f87` | |

- **60-30-10**：域色只出现在图标 / 环弧 / 发丝线 / 微图表 / 选中竖条，正文底色永远是 `surface` / `surface-raised`。
- **状态色不参与域色**：`warn` / `danger` 只表达「需要你注意」，不得当成某个域的主色。
- **任何新色必须同时给浅色覆盖**，否则浅色主题下必然低于 4.5:1。

### 1.3 诚实红线（No fake facts）

完整规则见 skill `references/honesty.md`，四条必须背下来：

1. **读不到 ≠ 0**：未就绪 / 采集失败显示 `—` 或原因文案，绝不画 0 弧、不写 `0 B`。
2. **失败即隐藏**：平台无此口径（Windows 无压缩 / 无换页计数）整段不渲染，而不是占位「不可用」。
3. **推导值必须标注**：算出来的数字（如「缓存·可回收 = 总量 − 已用 − 可用」）用斜纹 + tooltip 写明推导，不得伪装成实测。
4. **口径进 tooltip**：换算方式、平台差异、时间窗、分母语义一律 `title=` 承载，不上版面。

## 2. 版式预算（1000×700 硬约束）

窗口 1000×700 是主窗口唯一尺寸。任何一屏都必须**不滚动**装下。

```
1000 宽 = 58 rail + 942 内容
 700 高 = 40 titlebar + 660 内容
```

### 2.1 页面骨架（三段式，顺序不可换）

```
① Ribbon 状态带      62px   顶部速读，3–7 段
② Hero 主区块       118–160px  该页的核心量（环 / 构成条 / 主表）
③ 内容区            flex:1   磁贴网格 / 列表 / 表格
```

- 只有 ③ 允许 `flex-1 min-h-0 overflow-y-auto`；①② 一律 `shrink-0`。
- **禁止**给 ③ 里的卡片写死高度 + `overflow-hidden`：定高容器会挤压 flex 子项，口径行会被压成 1px（真实事故，见 §7.1）。
- 列表卡片用 `h-full min-h-[104px]` 撑满网格单元，让高度由网格决定。

### 2.2 高度预算示例（内存页设计稿）

| 区块 | 高度 | 说明 |
|---|---|---|
| Ribbon | 62 | 6 段 |
| gap | 9 | 区块间距 9–10 |
| Hero | 118 | 构成条 + 压力环 |
| gap | 9 | |
| 磁贴行 | 104 | 2 列 |
| gap | 9 | |
| 泄漏/提醒带 | 62 | 无命中则 0（不占位） |
| gap | 9 | |
| 列表 | 余量 ≈ 250 | 5–6 行 |

> 新增一个区块前先算总账：`660 − padding(27) − 各区块 − gaps`，余量必须 ≥ 0。

### 2.3 栅格与间距

- 卡片网格：`grid gap-2.5`（10px）；列数用 `repeat(auto-fill, minmax(240px, 1fr))`，不写死 `grid-cols-N`。
- 侧栏宽度：家族/列表栏 300–350px，用 `shrink-0`；主区 `min-w-0 flex-1`。
- 卡内 padding 10–14px；区块间距 9–10px（比 v5 的 16 更紧，因为一屏信息量更大——这是本叠加层的显式放宽）。

## 3. 组件契约

**先复用，再造新**。已存在的基元不得在页面里重画一份「差不多」的。

### 3.1 `Ribbon`（`src/components/Ribbon.tsx`）

| 导出 | 用途 |
|---|---|
| `RibbonShell` | 长条外壳：`h-[62px]` + 段间 hairline + 圆角裁切，`ariaLabel` 必填 |
| `RibbonSeg` | 一段；给 `onClick` 渲染 button（导航 / 切排序），不给渲染 div |
| `RibbonChip` | 非百分比位的图标芯片（26px 底衬 + 域色图标） |
| `RibbonValue` | 读数：mono 17px + 弱化单位，`tone` 只改颜色 |

规则：
- 段数 3–7；**段内不放名词标签**，语义由图标 + `title` 承载。
- 段必须等分（`flex-1`），不允许某段独占两倍宽——例外：`RibbonSeg` 内部图表可自适应。
- 同一产品只允许两种带子形态：**总览/应用页的域读数带**、**各页自己的口径带**；不得出现第三种长相。

### 3.2 `MiniGauge`（`src/components/stats/MiniGauge.tsx`）

三通道分工：**环弧=量感 / 环心图标=语义 / 旁侧 mono 数字=精确值**。

- 只给 0–100% 的量套环（CPU、内存、磁盘、电池、Swap、压力）。
- **禁止**给速率、计数、温度、字节数套环——环只表达「占满程度」，硬套会稀释语义。
- `ratio = null`（读不到）时只画空轨道，不画 0 弧。
- 尺寸 24（磁贴）/ 26（状态带）；`stroke` 2.2–2.4；图标约 `size × 0.45`。

### 3.3 `InfoTile`（`src/components/stats/InfoTile.tsx`）

三层克制文字，顺序固定：

```
[仪表/图标] 标题(11px dim)                    →
23px mono 读数 + 单位
一行口径(10px faint，单行截断)      ← 可为 string 或 ReactNode
卡底微图表（shrink-0）
```

- 标题可省（图标足够自明时），但**读数与口径行不能同时省**——只剩图标 + 数字的卡是空卡。
- `main` 缺省时显示 `note`（读不到的原因），绝不显示 0。
- 卡面装饰只有两样：顶缘 6% 域色洗光 + 底缘 2px 发丝线；不做投影堆叠、不做玻璃拟态。

### 3.4 行式组件（表 / 族行 / 大户行）

- 行高：表行 28px、密行 24px；hover `bg-chip`；选中 `bg-accent/[0.10]` 或域色 12%。
- 数值列右对齐 + `tabular-nums`；名称列 `truncate`；单位用 9–10px `text-ink-faint`。
- 行内比例条统一 3–4px 高，底色 `bg-chip`。

### 3.5 `AppIcon`（`src/components/AppIcon.tsx`）

真实图标 → 字母徽标（家族哈希渐变）→ 也要画徽标。**永不显示占位灰图**。

## 4. 文字纪律

### 4.1 字号阶梯（v5 §2.5 + 本层扩展）

| 角色 | size | 用在哪 |
|---|---|---|
| 页名 | 13.5 | topbar |
| 卡片标题 | 11.5 / 11 | 卡片头 |
| 正文 | 11.5 | 说明 |
| 表内主值 | 12 | 行标题 |
| 标签 | 10.5 | 字段名 |
| 口径行 | 10 | 磁贴读数下方 |
| 徽标 / 脚注 | 9.5 | **下限，不得更小** |
| 带内读数 | 17 | Ribbon value |
| 卡内大读数 | 23 | InfoTile main |
| Hero 数字 | 25–28 | 环心 |
| 页级 Hero | 40 | 总览可回收量 |

> 现有代码里存在 7–9px 的历史遗留（主要在灵动岛/图标内），**新代码禁止**。

### 4.2 三层文字上限

任何卡片最多同时出现三层文字：**标题（11px dim）→ 读数（23px mono）→ 一行口径（10px faint）**。
第四层信息（换算、来源、时间窗、完整列表）一律进 `title` tooltip 或下钻页面。

### 4.3 数字排版

- 所有数值：`font-mono` + `tabular-nums`；单位不参与等宽（用 `<small>` / `text-[10px]` 弱化）。
- 负数用 `−`（U+2212），增速用 `+`；缺失值 `—`（em dash），不用 `-` 不用 `0`。
- 字节 / 速率走 `formatBytes` / `formatSpeed`，不在组件里拼单位。

## 5. 新增页面 DoD（八条，缺一即未完成）

1. **设计稿先行**：`output/design/<page>-eul-mockup.html`，深/浅双主题截图验证无重叠溢出。
2. **骨架合规**：Ribbon → Hero → 内容，且总高度 ≤ 660 不滚动。
3. **图形锚点**：每个区块有图标/环/条/走势之一；百分比才套环。
4. **文字 ≤ 三层**：多出的口径全部进 tooltip。
5. **域色正确**：只用 §1.2 表里的色，且浅色主题下有覆盖值（截图对比度 ≥ 4.5:1）。
6. **诚实四检**：读不到显示 `—`、平台无口径整段隐藏、推导值斜杠纹 + 说明、口径进 tooltip。
7. **复用基元**：`Ribbon*` / `MiniGauge` / `InfoTile` / `CellBar` / `AppIcon`；未复用的必须在 PR 说明理由。
8. **门禁绿**：`npm run build`（tsc + i18n + docs + design + vite）+ 真机截图。

## 7. 反模式（都真实发生过）

### 7.1 定高卡片裁字
`h-[104px] overflow-hidden` 的磁贴里，flex 子项被压缩：口径行变 1px、下载卡变半截字。
**正解**：`h-full min-h-[104px]` 撑满网格单元 + 口径行/图表 `shrink-0`。

### 7.2 CSS 类名撞车
设计稿里给「泄漏行的家族名」用了 `.fam`，与左栏家族行 `.fam`（`flex:1`）撞车，元素撑到 584px 把整条带子顶出窗口。
**正解**：设计稿的类名带前缀（`.leak-famtag`），组件层用不同组件而不是复用同名 class。

### 7.3 用 rotate 拼图标
上传卡曾用 `<DownloadIcon className="rotate-180">`，与下载卡共用一个「带托盘横杠」图标。
**正解**：成对图标（`UploadIcon` / `DownloadIcon`，纯箭头无横杠）；方向靠图形定义，不靠 transform（门禁 R1 阻断）。

### 7.4 五个同权重数字并列
内存页曾把「物理 / 已用 / 可用 / 压缩 / Swap%」五个数字并列成 2 列网格，视线无处落脚。
**正解**：只留一个主读数（已用），其余降为图例或状态带段，用堆叠条承载构成关系。

### 7.5 空卡
删标题删过头，卡片只剩「环 + 数字」，用户反馈「卡片内容太空」。
**正解**：保留标题 + 一行口径（`InfoTile` 三层），完整口径仍走 tooltip。

### 7.6 假动作按钮
设备页没有全局刷新语义却挂了刷新按钮。
**正解**：按钮的语义不存在就整颗隐藏，不做「点了没变化」的假动作。
