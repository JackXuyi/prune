01三条原则
A
一屏一个主数字。面板首屏是「内存已用 / 总量」与「可回收 GB」两行；存储页是 22px 的可回收总量。其余读数一律降级为副行，不与之争抢。
B
线只画一条，卡片不再套卡片。分组用 1px hairline 与 16–20px 留白表达；只有「需要临时高亮的结果条」（清理完成、泄漏命中）才允许一层次淡底色。
C
颜色是状态，不是装饰。正文只用 ink / ink-dim / ink-faint；accent 只给可行动的数值；warn 与 danger 只在异常时出现，正常态全屏看不到暖色。

06本轮相对 v1 的改动
01
面板 hero 归因收进 tooltip。v1 存储行右侧挂着「🟢 12.4 GB 跨平台二进制 · 剩余 78 GB」三件事，v2 只留「可回收 · 剩余」，A1 归因悬停可见。
02
应用列表行高从 2 行压到 1 行 + 3px 细线。10 条从溢出滚动变成一屏放下 8 条，仍保留进程数与口径后缀。
03
主窗口省掉一整行 chrome。48px 单行承载品牌 + tab + 口径 + 时间 + 刷新，内容区多出 36px。
04
存储页主数字 22px。可回收量从「一行文字」升级为页面锚点，卷容量与分层都成为它的注脚。
05
L1–L4 从 2×2 卡片矩阵压成 4 条对齐行。同一列数值纵向可比，扫读速度提升，且省出约 70px 高度。
