## ⓪ 前置事实与统一原则（排在定价、锚点、工期之前）

### #0 LICENSE 阻塞项（第 0 行，须最先拍板）

**M26 要补的 MIT LICENSE，使「功能 gate」在法理上不成立**：任何人 `git clone && cargo build` 就得到一份合法、完整、含全部功能的二进制。MIT 之下没有 gate，只有「15 分钟编译 vs 付 $29」的便利性交换。推论：

- 任何「批量归档执行需 license」不是权利边界，是官方构建的边界——拦不住人，只提供便利。
- 联网验签排除：只约束官方产物、约束不了自编译，还要重启后端、破坏零网络定位——为无效手段付两次代价。
- **source-available 不可选**（不是性价比问题）：开源可审计正是「不撒谎」叙事的证据链，卖它换 $1–3K 收入是拿资产换零钱。
- 只剩两条真路：(a) MIT + 放弃 gate → B2；(c) MIT + 卖「签名构建 + 自动更新 + 支持」的便利费（现实区间 **$10–20 一次性或 $2–5/月，不是 $29**——用 230–360 单的算术规划它会系统性高估）。

### 统一原则：「不新增无法自证的商业陈述」

四个「不」是同一条原则的四次应用，举证责任在 gate 一侧（不可逆折损 vs 可逆收入的举证门槛不对称）：

| 不 | 理由（无法自证之处）|
|---|---|
| **不 gate** | MIT 下功能排他性无法自证 |
| **不划线原价** | 被比较价无真实成交，无法自证 |
| **不遥测** | 无法向用户交代的数据流，无法自证为"必要" |
| **不做 Windows 路线**（条件句保留）| 付费意愿是未验证假设，无法自证 |

**B2 的正当性即来自此**：它是唯一「叙事—license—产品行为」三者同向的配置——零遥测 + MIT + 零权限第一次互相自洽；不需要识别存量用户、不需要验签、不需要解释「为什么最强的东西免费、收费的是替代品」。**功能 gate 下"最强能力免费、收费的是替代品"会持续制造"作者把好东西藏起来了"的观感——gate 每多存在一天，Prune 唯一耐久的资产（不撒谎）就折损一点；B2 下同样的能力是赠予而非扣留。**

## ① 一句话理解

Prune 是**危机驱动的"安全删除保险"**：真需求成立但极窄。功能 gate 在 Prune 上**穷举后为空**——商业化的三条理由（$9 算术 / $49 可达性 / 抢窗口）全部被否，锚点供给在三个时刻全部错位。终局结论：**不做功能商业化；唯一紧急的事是免费发布与装机（获客窗口），唯一不紧急的事是商业化本身（定价窗口已死）；其余全部等 R15 三读数。**

| 画像 | 特征 | 付费行为 |
|---|---|---|

| **Xcode 重度 iOS 独立开发者** | 被 DevCleaner $59 教育过付费 | 付费能力最强，但已有替代品选项 |

**反画像**：学生/免费脚本用户（vibe-code 替代品文化）；CleanMyMac 全家桶用户；已持 Vitals 用户。

**场景硬数据**：磁盘红危机 + AI 吞盘失控感是仅有的两个强场景；Agent 采用率（JetBrains 2026：90% 每周用）口径限定为自报专业开发者，支撑高频回访的只有重度 1/3。监控/局域网拓扑/宠物 ≈ 功能面 80% 是维生素；"装完即忘"是结构性形态（30 天留存 2–4%），留存无法靠功能修复。

## ③ 真实痛点与三时刻错位

**四真问题**：①删了不会出事的确定性（命中，被隐私矛盾+归档确认例外+归档路径无熔断侵蚀）②AI 吞盘的控制权（部分命中）③"值多少"（未命中）④危机后遗忘断层（未命中，非功能可解）。

**三时刻错位（本方案商业结论的承重结构，三层各自独立、互不重叠）**：

| 时刻 | 状态 | 可测指标 |
|---|---|---|
| 需求时刻（盘红）| 只想删除，无心做购买决策 | 盘占用率 |
| 决策时刻（首扫）| 大数字是惊讶不是危机，无痛感 | **首扫后 24h 内是否执行过一次清理**（行为优于代理）|
| 可售时刻（非危机批量管理）| 用户不在场（留存 2–4%）| 第 8 天回访率 |

**任一层改善都不足以翻案，必须三层同时被打破**；且三层数据全部依赖分发才能观测——**观测本身是一笔支出**（落点 = 发布运营 3–5 天）。翻案条件 = 「先支付分发成本，再读三层数据；三层须同时被打破」。

**竞争证据修正**：Spookle（2026-10-24 上线）逐字产品化"AI 只读人执行"且更可感知——**情报流程失效确认，今后所有"X 仍无竞品"论断一律标"未经证实"**；RAMWatcher 追平 footprint 口径；免费克隆洗劫清理场景；DevCleaner 收费墙证据弱（安装 2,200+）。免费层矩阵：Prune Free 在清理广度上是 Spookle Free 的真子集（缺卸载残留/AI agent 幽灵清理/端口↔repo），在探测深度上是超集。

## ④ 结构化需求 · 终稿 v4

### 功能 gate 穷举表（终局命题，不可被单个反例打掉）

**「危机时刻可售物 = 已经被免费赠送的集合」**——危机时刻唯一有独家供给的东西（如只有 Prune 能指出的跨平台二进制）已被免费赠送，收回它触发自家护栏（只 gate 新功能 → 需要 grandfathering → 而那条护栏一旦需要就说明错了）。逐项穷举：

跨平台二进制（已免费）/ 重复存储（已免费）/ footprint（已免费）/ AI 缓存（对手有）/ Xcode 深扫（对手有）/ 幽灵进程（Spookle 有）/ Docker 执行（定位红线）/ 归档（可逆性无定价承载力且 free 路径更快）→ **穷举后为空**。唯一未死的一行是 Windows（未发布过、对手无），但它是**候选不是路线**（见 §⑥ M31）。

**可逆性不能作为付费理由（阈值型判定）**：付费意愿 ∝ 不可逆损失量级；损失可自行恢复或恢复成本 < 价格 10 倍 → 承载力 ≈ 0。node_modules 重装 5–20 秒/项 ≈ $0.1–1，远离阈值；Time Machine/Git 能收钱是因为丢的是数据不是重装。**Prune 扫描的全部资源都是可重建的——专做可重建资源清理的产品，天生没有资格卖"可逆性保险"。** 这解释了为什么 Spookle/DevCleaner 的 Pro 卖自动化与广度、不卖安全。

### 文案红线（对价陈述失实一类，三条）

1. **禁排他性句式**：禁「只有 Pro 才能批量归档」，也禁看似中性的「Pro 版支持批量归档」——"Pro 版"本身暗示非 Pro 版不支持，而 MIT 下自编译版支持。**一律描述句：「官方构建提供批量归档 + 自动更新 + 支持」。**
2. 禁划线原价/假挂牌期/倒计时。
3. 「不可逆删除必须持有 `Confirmed`；可逆操作必须证明还原可达」为可测试断言；对外禁「每次删除都要你点确认」绝对句（v0.9.0 已为假）。

### Won't 清单（终版）

订阅/年费｜功能 gate（MIT 下无法自证）｜在线校验/设备指纹/解绑｜grandfathering（作废，见护栏）｜预售页（卖假设）｜划线原价/假挂牌期/倒计时｜安装侧遥测｜🟡 转 Pro｜mtime 回溯估算｜"任何删除都需人确认"绝对断言｜treemap/卸载器/风扇/软件更新｜Windows 完整化路线（降为条件句候选）｜MAS 上架｜source-available。

### 护栏两条（结构性）

1. **任何需求若需要 grandfathering ⇒ 正在收回既有能力，违反「只 gate 新增功能」，打回重设计**（grandfathering 从需求中删除，升级为护栏）。
2. 禁排他性暗示与禁划线原价、禁倒计时同属**对价陈述失实**一类。

## ⑤ 推演与风险（终局账，全程未被松动）

- **期望值**：功能商业化中性 ≈$3K / 乐观 ≈$12.1K（扣退款）；回本线（$16K 现金机会成本口径）**四档全不达**——这条结论没有因任何一轮讨论松动。MIT 下便利费现实量级 ≈$1–2K。B2/Sponsors 现实量级 ≈**每月几十到几百美元**。
- **窗口分层（修订 18）**：**定价窗口已死**（4–5 周工程 > Vitals storage map 1–3 个月窗口；且 MIT 下无 gate，无心智可卡——原 roadmap D2「晚收比早收难」整条删除）；**获客窗口活且升为第一优先**——理由从竞争改挂收入结构：功能 gate 塌了 → 收入只剩 装机 × 转化，转化项整体塌陷 → **装机从瓶颈之一变成唯一变量**。即使 Vitals 明天放弃 storage map，获客仍是第一优先——理由不依赖对手动作。
- **紧迫性分层**：紧急·现在做（0 工程）= 免费发 v0.9.1 + 落地页 A/B 三读数 + Sponsors 开通；不紧急 = 4–5 周工程与商业化（等验证结果，不为赶工牺牲质量）。
- **工期证伪**：批量归档未做（M30 原文"批量归档与 CLI 子命令未做"）；工程 7–12 天 + **发布运营 3–5 天（原全案漏算，而获客才是瓶颈）** + MoR 审核 5–7 工作日（关键路径 = 发布运营 + MoR 审核，不是授权模块；Paddle 新站有 3×3 周拒审先例）→ **4–5 周 = 验证通过后的开工量**。
- **最坏情况与退出**：最坏 = 4–5 周沉没 + ≈$2K 现金换 <30 单，且付费墙打掉唯一获客渠道（口碑）。退出成本极低（无后端/无授权服务器/Pro 可一键全量免费）；**真正不可逆的只有一件：在 MIT 项目上宣告功能排他性——对价陈述失实，回滚不了叙事**。
- **对称偏差披露（两句并列，必须同时写）**：方案作者因产出压力偏向「能落地」（撤回 9 条判断，多条是写死后才被打中）；评价者因不承担造价偏向「不做」（红队自陈错误集中发生在给出具体量时——≤20 上限、$49"不可能"、OS"唯一杠杆"、批次确认"伪安全"）。**红队结论是筛选器，不是决策**——用于砍方案，不用于定量。
- **穷举修正**：「危机时刻可售物 = 空集」有反例（危机时"找出别处找不到的 GB"），改为「**= 已经被免费赠送的集合**」——从"推理为空"升级为"**穷举后为空**"，不可被单个反例打掉。穷举表唯一活着的行是 Windows（见 §⑥ M31）。

## ⑥ MVP 方案（执行顺序 + 平权三选项）

### 执行顺序（重要度高于工期本身）

```
① 拍 LICENSE（第 0 行，定 MIT；source-available 不可选）
② 免费发 v0.9.1（0 工程）+ 落地页 A/B（0 工程）+ 开 Sponsors（0 工程）；发布运营 3–5 天计入（这就是支付分发成本）
③ 4 周读装机与三层数据：<3,000 或单周 <800 即止，判负一分不花
④ 三层同时被打破才翻案（装机达标 且 留存显著高于 2–4%）；判正才开工 4–5 周
```

翻案前提再强调一次：**三层数据是花钱买来的观测，不是自然发生的观测**——"等数据"不得成为不投入的借口。

### S1 三选项（平权并列，不给推荐排序）

| 选项 | 内容 | 代价（原样呈现）| 可逆性 |
|---|---|---|---|
| **甲·为便利定价** | 官方构建 + 自动更新 + 支持，$10–20 一次性 | 4–5 周开工量（验证通过后）+ 每 6–8 周发布承诺 + 三类合规敞口；读数不达标则工程不可退 | 低 |
| **乙·先验证不定价** | 不做 gate，先跑 R15 三读数 | 验证需要流量，而流量正是缺的那环；大概率停在不可判定状态——成本已付、结论未出 | 高，但时间不可退 |
| **丙·不设价格（B2）** | 免费全功能 + Sponsors/一次性支持/招聘板；**是这场讨论推出的结论，不是退路**——三件套（零遥测+MIT+零权限）在此唯一互相同向 | 放弃收入可能（每月几十到几百美元）；等于承认它是作品集而非生意；但保住叙事完整性与发布节奏自由 | 高 |

三个选项的差别不是优劣，是三种不同的赌注——**团长不替决策者承担赌注，故不给排序**。

### M31 Windows（降为条件句候选，不是路线）

- 唯一未死的候选（未发布过 → 不触发"只 gate 新功能"护栏；Vitals 仅 waitlist、Spookle 无），**但付费意愿本身是未验证假设**——Mole/CacheCleaner/DevCleaner 全是 macOS，既可读作"没发现机会"，也可读作"算过，不值得"（Windows 免费清理工具极密集，开发者付费意愿低）。
- 三限定 + 一条永续成本：三个独家能力只有一个可迁移（footprint 无 Windows 等价物 → Windows 版是"没有灵魂的清理器"）；自动滑入广度竞争（定位红线）+ UAC 破零权限；**Windows 固定成本永续（签名 $200–400/年 + SmartScreen 声誉）vs 买断第一年后收入趋零——数学上要求永续新增销售，与"收缩维护面"相反**。
- **条件句**：「若 macOS 侧证明付费意愿存在，则 Windows 是唯一可迁移方向。」验证顺序：先在 macOS 证明，再谈移植（双重不确定不叠加）。
- 这给了 M31 第一个真正的收入理由（此前只有定位理由），但只作为候选登记，不排期。
