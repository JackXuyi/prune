# M18-LAN 设备页卡片化重设计方案

> 范围：`src/components/LanBoard.tsx`（端口 tab → 局域网分段）。只改前端展示层，不动 `lanStore` 数据结构与 Rust 侧。

## 1. 问题诊断（现状表格的问题）

| # | 问题 | 现状表现 |
|---|------|---------|
| P0 | 设备可读性差 | 32 行同质化表格，「未知」占多数，扫一眼抓不住重点 |
| P0 | 状态不显性 | 在线/离线只是一列小字，需要逐行扫读才能判断网络健康度 |
| P1 | 图标语义弱 | `kindGlyph` 单字符（⌂ ▣ ▯）辨识度低，设备类型要靠文字标签二次确认 |
| P1 | 摘要信息埋没 | 暴露端口数、探测进度挤在一行 11px 小字里，核心安全信号权重不足 |
| P2 | 「连了我」位置突兀 | 安全事件混在设备名列中，容易漏看 |
| P2 | 无筛选能力 | 想看「谁在线」「谁连过我」只能人肉过滤 |

## 2. 设计目标

一句话：**从「扫一行表格」变成「扫一眼仪表盘」**——在线状态、设备类型、对我暴露面三个核心问题在 3 秒内得到答案。

## 3. 信息架构（四层）

```
筛选条（全部 / 在线 / 连了我 / 重扫）
├─ 指标卡 ×3   在线 N/M · 对我开放端口 · 扫描耗时
├─ 提示条      随机 MAC / 异常 notes（保留现有 warn 语义）
├─ 分组卡片区
│   ├─ 本机与网关（置顶固定，最多 2-3 张）
│   ├─ 在线设备（卡片网格，3 列）
│   └─ 已离线（折叠行，展开后置灰列表）
└─ 元信息脚注  总数 · 扫描耗时 · 时间 · IP 聚合口径说明
```

## 4. 设备卡片规格

```
┌─────────────────────────────────┐
│ [图标tile]  设备名 · 厂商     ●  │  ← 状态点：绿=在线 琥珀=最近在线 灰=离线
│             MAC(弱化/随机MAC)    │
│ [192.168.0.44] [连了我 5198…]    │  ← IP mono 徽标 + 事件标签
└─────────────────────────────────┘
```

- **图标 tile**：34px 圆角方块，`kind` 映射 SVG 线性图标（电脑/手机/路由器/NAS/打印机/电视/音箱/摄像头/IoT/未知），替换现有 `kindGlyph` 单字符。tile 背景用域色 14% 透明度。
- **域色映射**（沿用 `--color-domain-*` 与现有 token，低饱和）：
  | 设备类型 | 图标色 |
  |---------|--------|
  | 路由器/网关/本机 | accent `#34d399` |
  | 电脑/手机/平板 | info `#6aa9ff` |
  | NAS | domain-net `#22d3ee` |
  | 电视/音箱/摄像头/IoT | domain-cpu `#a78bfa` |
  | 打印机/未知 | ink-dim `#99a1aa` |
- **状态点**：`online` 绿 / `stale` 琥珀（文案「最近在线」）/ 离线灰，置于卡片右上角。
- **主标题（设备名优先）**：`hostname`（去 `.local` 后缀，来自 mDNS）作为卡片主标题；hostname 为 `null` 时回退到角色名/类型名（本机 → 网关 → 路由器/打印机/未知…）。**不虚构名称**——查不到就是查不到，回退而不是编造。
  - 展示形态：`iPhone-de-xiaoming`（hostname 命中）；`电脑 · Microsoft` / `未知`（回退）。本机固定显示「本机」，网关固定显示「网关 · 路由器」。
- **副标题**：vendor（MAC 厂商）；随机 MAC 时显示「随机 MAC」并弱化。vendor 与 hostname 同时缺失时副标题留空，不留「—」噪音。
- **「连了我」升级为卡片级 warn 徽标**（`连了我 5198 / 31383 …`），inbound 命中的卡片加 warn 1px 描边，安全信号前置。
- **mDNS/SSDP 服务**：显示为 `ln-tag` 小标签（ipps / smb / airplay…），最多 3 个。
- **IP 徽标**：mono + `surface-overlay` 底，点击复制 IP（后续可加 hover copy icon）。

## 5. 交互设计

| 交互 | 说明 |
|------|------|
| 筛选 chips | 全部 / 在线 / 连了我，单选，与搜索语义独立；「连了我」命中 `inbound.length > 0` |
| 分组折叠 | 离线设备默认折叠为一行「已离线 N 台」，展开后卡片降透明度 55% |
| 点击卡片 | 展开/收起详情行：完整 MAC、全部 services、全部 inbound 端口、复制 IP/复制 MAC |
| 重扫 | 保留现有进度条态（scanning 分支不动），重扫按钮并入筛选条右侧 |
| 铁律不变 | **进入分段不扫描**——首次空态与授权说明文案原样保留 |
| 动效 | 卡片入场沿用 `prune-count-in`；全部尊重 `prefers-reduced-motion` |

## 6. 布局与响应

- 网格：`repeat(auto-fill, minmax(330px, 1fr))`（220px 基础稿经真机走查放大 1.5 倍）——主窗口窄时自动退化为 2 列/1 列。
- 指标卡沿用项目「域卡 24px」规范；卡片圆角 10px（介于 `radius-hero` 与 `md` 之间，与现有卡面一致）。
- 信息密度优先：单卡高度控制在 ~86px（两行内容），不引入第三行。

## 7. 实施步骤（T1–T3）

| 阶段 | 内容 | 验收 |
|------|------|------|
| T1 | 新建 `DeviceCard` 组件 + `kindIcon(kind)` SVG 图标集（放 `components/icons.tsx`） | typecheck 0 错误 |
| T2 | 重构 `LanBoard.tsx`：指标卡 + 筛选 chips + 分组网格 + 离线折叠；替换现有表格/`DeviceRow` | 三种状态（未扫描/扫描中/快照）渲染正确 |
| T3 | 交互补全：筛选、点击展开详情、复制 IP；对照本方案逐条走查 | 窄窗口 ≤420px 单列可读；reduced-motion 生效 |

风险与回退：纯展示层改动，`lanStore`/Rust 不动；保留 git 单独分支，回退只需 revert `LanBoard.tsx` + 新增文件。

## 8. 明确不做（本次范围外）

- 不做设备详情二级页（当前数据量不值得）
- 不做自动轮询扫描（违反「手动触发」铁律）
- 不改端口子页（`PortBoard` 主体）与 DotMatrix 仪表盘
